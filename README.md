# HCI Lab Assignment - Single-Page Cybersecurity Portfolio

This repository contains the source code and design layout for my single-page personal portfolio website built for the HCI Lab assignment.

## 📌 Links
- **Live Demo (GitHub Pages):** https://jay-lynnn.github.io/HCI_LAB_Project/
- **Wireframe:** https://www.figma.com/design/6qtoJmqoAQ1Ybrag8ceYJ6/Untitled?node-id=0-1&t=ReSyzxTp5qBvweic-1

## 🛠️ Built With
- **HTML5:** Semantic markup (`<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **CSS3:** Custom styling using Flexbox, CSS Grid, media queries, and pure CSS hover overlays (No JavaScript dependencies)

## 📁 Sections Included
1. **Hero:** Full-screen introduction with a dark gradient overlay
2. **About Me:** Overview and academic background
3. **Projects:** Interactive cards with pure CSS hover details
4. **Skills & Tools:** Technical competencies and cybersecurity tools
5. **Contact:** Direct email, GitHub, and LinkedIn contact details
